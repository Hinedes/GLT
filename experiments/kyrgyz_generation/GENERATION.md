## Interpretation

The outputs are not coherent Kyrgyz capability. Kyrgyz character fraction is high on Kyrgyz prompts, but greedy decoding never emitted EOS and averaged 128 tokens with high repetition. The side-by-side examples show copied fragments followed by repeated phrases, malformed continuations, and occasional replacement characters. Sampling improves distinct-4 and lowers repetition somewhat, but remains repetitive and does not establish coherent continuation. English OOD outputs are mixed-language/degenerate rather than a clean control. PPL and Cyrillic fraction therefore overstate capability here.

The first persistent attempt failed before generation because evaluation used `use_cache=True`, causing a `0.0009849956445613373` reload mismatch; evaluation was corrected to `use_cache=False` and generation alone uses cache. A first generation attempt also failed on BF16/FP32 Axis hook dtype mismatch; generation now uses the same autocast context as training.
